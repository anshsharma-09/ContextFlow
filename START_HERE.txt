1. Read README.md.
2. Windows + local MySQL:
   - Open backend/.env.example, copy it to backend/.env, enter your own MySQL credentials.
   - In a terminal: cd backend ; npm install ; npm run db:setup ; npm run dev
   - In another terminal: cd frontend ; npm install ; npm run dev
   - Open http://localhost:5173
3. Or use Docker Compose from the project root:
   - Copy .env.example to .env and set MYSQL_ROOT_PASSWORD.
   - Run: docker compose up --build
   - Open http://localhost:5173

Default AI_PROVIDER=demo: clearly labelled local demo output, no Gemini key required.
For real Gemini: set AI_PROVIDER=gemini and GEMINI_API_KEY in backend/.env (or root .env for Docker Compose).
Never share or commit API keys or DB passwords.
